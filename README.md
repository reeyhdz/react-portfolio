# Irving Acosta — Portafolio

Portafolio personal de Irving Acosta, desarrollado con Vite, React y Tailwind CSS.

## Secciones

- Header
- Acerca de
- Servicios
- Proyectos
- Contacto

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy en Vercel

El proyecto está listo para Vercel (`vercel.json`):

1. Importa el repo en [Vercel](https://vercel.com/new).
2. Framework: **Vite** (detectado automáticamente).
3. Build: `npm run build` → output `dist`.

En el dashboard de Vercel:

- **Analytics** → Enable (ya está integrado con `@vercel/analytics`)
- **Speed Insights** → Enable (integrado con `@vercel/speed-insights`)
